## [0.2.0] - 2026-11-24

### Added

- Twice epi-differentiability of Moreau envelopes, the converse direction of
  [Mordukhovich 2024, Cor. 1.101(a)]: `continuouslyProxRegularFor_of_lipschitz_gradient`,
  `ContinuouslyProxRegularFor.exists_twiceEpiDifferentiableAt_of_moreauEnvelope` and
  `ContinuouslyProxRegularFor.exists_twiceEpiDifferentiableAt_iff_moreauEnvelope`
  (`SecondOrder/EnvelopeTwiceEpi`).
- A docstring for every definition, structure, instance and theorem.
- API documentation at <https://david.villacis.net/lean-variational/docs/>, rebuilt on every
  push to `master`.
- Continuous integration on every pull request: build with no warnings, `lake exe mk_all --check`,
  the environment linters of Batteries, the docstring check and the axiom audit.
- Compiled release archives for Linux x86_64 and macOS arm64, used by Lake at a tagged `rev`.
- Package metadata in `lakefile.toml` (description, keywords, license).
- `CHANGELOG.md`, `CITATION.cff` and `ERRATA.md`.

### Changed

- `ConvexAnalysis` is pinned to `v0.1.1`, which builds with no warnings.
- Mathlib's standard set of style linters is enabled, and the library complies with it. Proofs
  were adjusted (`show` to `change`, `simp` to `simp only`, line lengths); no statement changed
  apart from the instance arguments below.
- **Breaking.** Twelve theorems no longer take instance arguments they did not use: nine lose
  `[DecidableEq K]`, `tendsto_multipliers` loses `[Fintype K]`, and `locallyClosed_iInter` and
  `locallyClosed_graph_lowerFeasible` take `[Finite ι]` instead of `[Fintype ι]`. Calls that
  pass these instances by name or by `@` need the argument removed.
- The root file `VariationalAnalysis.lean` is generated by `lake exe mk_all`.

## [0.1.0] - 2026-11-21

First tagged release: normal cones, subdifferentials, coderivatives, variational and extremal
principles, well-posedness, optimality conditions, SCD mappings and second-order theory, as
listed in `ROADMAP.md` at that tag.
